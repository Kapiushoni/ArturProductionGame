# Своя графика для игры

Здесь можно заменить любую деталь персонажей, предметов и интерфейса своей картинкой.

## Что где лежит

| Папка | Что это |
|---|---|
| `_catalog/` | Листы-каталоги: все детали персонажа с подписанными именами. Начинай отсюда. |
| `_originals/` | Оригинальные детали в том размере, в котором их рисует игра. Это шаблоны. |
| `hero/`, `boss/`, `skeleton-guard/`, ... | **Твои** картинки. Скрипты их никогда не трогают. |

Персонажи и наборы:

| Папка | Что это |
|---|---|
| `hero` | Джинн: тело, щиты, мечи, боевая гитара, эффекты |
| `skeleton-guard` / `-fire` / `-ice` | Скелет-страж (обычный, огненный, ледяной) |
| `skeleton-sentry` / `-fire` / `-ice` / `-snow` | Скелет-часовой (обычный, огненный, ледяной, снежный) |
| `boss` | Колдун Подземного мира |
| `items` | Предметы инвентаря |
| `interface` | Кнопки, окна, карта, меню |
| `backgrounds` | Фоны боя |
| `battle-effects` | Цифры урона, «Крит!», «Блок!» и т. п. |
| `loading-screen`, `tutorials` | Экран загрузки и картинки обучения |

## Как заменить деталь

1. Открой каталог, например `_catalog/hero.png`, и найди нужную деталь. Под ней написано имя, например `body/` `arm-3`.
2. Скопируй оригинал `_originals/hero/body/arm-3.png` в **свою** папку с тем же путём: `hero/body/arm-3.png`.
3. Нарисуй поверх (Photoshop, Krita, Paint.NET, Aseprite — что угодно), сохрани как PNG с прозрачным фоном.
4. В папке `web` выполни:
   ```
   npm run art
   ```
5. Обнови страницу игры (`npm run dev` → http://localhost:5173).

Вернуть оригинал: удали свой файл и снова выполни `npm run art`.

## Правила, чтобы всё встало на место

- **Размер картинки не меняй.** Игра растягивает твою картинку ровно в рамку оригинала. Если хочется больше деталей,
  можно рисовать в 2× или 4× размере, **сохраняя пропорции**: игра уменьшит её сама.
- **Положение внутри картинки важно.** Персонажи анимируются: игра двигает и поворачивает детали вокруг их точки
  крепления. Если рука на шаблоне прижата к левому краю, плечо должно остаться у левого края, иначе рука «оторвётся».
- **Фон прозрачный**, иначе вокруг детали будет прямоугольник.
- Можно класть и векторный `.svg` с тем же именем вместо `.png`.
- Одна и та же деталь часто используется в нескольких позах. Например, `arm-3` может быть и в атаке, и в покое,
  поэтому после замены проверь разные анимации.

## Команды

| Команда (в папке `web`) | Что делает |
|---|---|
| `npm run art` | Пересобирает графику только тех персонажей, у которых ты что-то добавил, изменил или удалил |
| `npm run art -- --all` | Пересобирает всех персонажей, у которых есть твои файлы |
| `npm run art:kit` | Заново делает `_originals` и `_catalog` (нужно, только если поменялись имена деталей) |

Имена деталей задаются в `web/tools/parts/names.mjs`.

## На другом компьютере

Всё нужное лежит в репозитории: твои картинки (`web/custom-art`) и исходники игры (`web/source`: детали в SVG,
Flash-файлы, исходный код и звуки). Достаточно:

```
git clone https://github.com/Kapiushoni/ArturProductionGame.git
cd ArturProductionGame
npm install
npm run art -- --all
npm run dev
```
